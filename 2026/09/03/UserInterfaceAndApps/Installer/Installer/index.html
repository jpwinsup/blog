Windows Installer キャッシュの削除可否について

Published Date: 2026-09-04
User Interface and Apps►Installer
feedback 共有

本記事はマイクロソフト社員によって公開されております。

こんにちは、Windows サポート チームです。

システム ドライブの空き容量を確認したところ、C:\Windows\Installer フォルダーが大きな領域を使用していたため、配下のファイルを削除してよいか、というお問い合わせをいただくことがありますが、このフォルダー配下のファイルの削除は、大変危険です。

そこで今回は、Windows Installer キャッシュの役割、手動で削除できない理由、およびキャッシュされた MSI ファイルから製品の製造元を確認する方法をご紹介します。

概要

Windows Installer キャッシュは、Windows Installer を使用してインストールされた製品の保守に必要な重要なファイルを保持する領域です。既定では C:\Windows\Installer フォルダーが使用されます。

結論として、C:\Windows\Installer 配下のファイルやフォルダーを、空き容量確保を目的として手動で削除することは推奨しておりません。

キャッシュを削除すると、その時点では問題が見えなくても、後から製品の更新、修復、アンインストールを行った際に失敗してしまい、更新も修復もアンインストールも何もできなくなってしまいます。
もし、容量の削減が必要な場合は、キャッシュを削除するのではなく、対象製品の開発元またはサポート窓口にご確認いただき、ご案内する手順をご確認ください。

1. Windows Installer キャッシュの詳細

MSI ファイルを使用して製品をインストールすると、Windows Installer は、以後の製品保守に必要なファイルを Windows Installer キャッシュへ格納します。また、MSP ファイルを使用して製品へ更新プログラムを適用した場合にも、保守に必要な情報が追加されます。

MSP ファイルは、Windows Installer ベースのアプリケーションへ更新プログラムを配信するためのパッチ パッケージです。製品の更新が繰り返される環境では、インストールされている製品や適用済みの更新プログラムに応じて、Windows Installer キャッシュの使用量が増えることがあります。

キャッシュされたファイルは、主に次の操作で使用されます。

  • 製品の更新
  • 製品の修復
  • 製品のアンインストール
  • 適用済みパッチの管理

C:\Windows\Installer 配下のファイル名は、元のインストール パッケージ名や製品名と一致しない場合があります。また、製品ごとにキャッシュされるファイルの種類や数、必要となる容量は異なります。このため、ファイル名、作成日時、サイズだけで、不要なファイルかどうかを判断することはできません。

参考情報:

  • 不足している Windows インストーラー キャッシュ ファイルを復元する - Windows Client
  • パッチ パッケージ - Win32 apps

2. 手動で削除できない理由

Windows Installer キャッシュ内のファイルは、単なる一時ファイルではありません。Windows Installer が、インストール済み製品の更新、修復、アンインストールなどを行うために使用するファイルです。

このため弊社技術情報でも、Windows Installer キャッシュは削除しないよう案内されています。キャッシュが欠損しても、通常使用している間は直ちに問題が発生しないことがあります。しかし、その後に製品を更新、修復、またはアンインストールした際、必要な MSI ファイルや MSP ファイルが見つからず、処理に失敗するリスクがあります。

キャッシュの欠損に関連して、セットアップ ログや MSI の詳細ログに、次のようなエラーが記録される場合があります。

  • エラー 1612: この製品のインストール ソースを使用できない
  • エラー 1635 / 1636: Windows Installer の MSP ファイルを処理できない
  • エラー 1642: 対象製品が見つからない、または対象バージョンが一致しない

また、キャッシュされたファイルは、そのコンピューター上の製品のインストール状態に対応する一意のファイルです。このため仮に別のコンピューターから同名または類似のファイルをコピーしても、正しく復旧できるとは限りません。弊社技術情報でも、欠損したファイルだけを以前のバックアップから置き換える方法ではなく、必要に応じてシステム状態の完全な復元や、OS とアプリケーションの再インストールが必要となる場合があることも説明しています。

重要
C:\Windows\Installer 配下の MSI、MSP、サブ フォルダーを手動で削除しないでください。レジストリとの照合だけで「孤立している」と判断するツールや、キャッシュの一括クリーンアップをうたうサード パーティ製ツールについても、実行前に対象製品の開発元へサポート可否をご確認ください。

容量を削減したい場合

Windows Installer キャッシュだけを対象とする、すべての製品に共通した安全な手動削除手順はありません。削除や容量削減の方法は、キャッシュを使用している製品ごとに異なります。

まず、後述の方法でキャッシュ ファイルに記録された製品名や製造元を確認し、対象製品を特定します。そのうえで、次の対応を検討してください。

  1. 製品の開発元またはサポート窓口へ、キャッシュ容量を削減するためのサポート済み手順があるか確認します。
  2. 製品側で古い更新プログラムを整理する機能が提供されている場合は、その手順に従います。
  3. 製品のアンインストールと再インストールを行う場合も、事前に製品固有の手順、前提条件、データのバックアップ方法を確認します。

製品をアンインストールして最新バージョンを再インストールすることで、過去のパッチ管理データが整理される場合があります。ただし、実施可否や具体的な手順は製品によって異なり、キャッシュが既に欠損しているとアンインストール自体が失敗する可能性もあります。必ず製品の開発元が案内する方法に従ってください。

参考情報:

  • 不足している Windows インストーラー キャッシュ ファイルを復元する - Windows Client

3. MSI キャッシュの製造元を確認する方法

Windows Installer キャッシュ内の MSI ファイルは、元の製品名と異なる名前で保存されていることがあります。MSI データベース テーブル エディターである Orca を使用すると、MSI ファイル内の Property テーブルから、パッケージに記録された製品情報を確認できます。

Orca は Windows SDK の「Windows Installer Developers 向けコンポーネント」として提供されています。導入方法については、次の公開情報をご確認ください。

  • Orca.exe - Win32 apps
  • Windows インストーラー開発者向けの Windows SDK コンポーネント

確認手順

注意
Orca は MSI データベースを編集できるツールです。調査対象のキャッシュ ファイルを直接編集しないでください。必要な権限を持つ管理者が、対象の MSI ファイルを作業用フォルダーへコピーし、コピーしたファイルを参照用として開いてください。元のファイルは移動、名前変更、削除しないでください。

  1. C:\Windows\Installer で、確認対象の拡張子が .msi, .msp のファイルを特定します。
  2. 対象ファイルを作業用フォルダーへコピーします。
  3. Orca を起動し、メニューの File - Open から、コピーした MSI ファイルを開きます。
  4. 左側の Tables 一覧から Property を選択します。
  5. 次のプロパティを確認します。
プロパティ 確認できる情報
ProductName インストール対象としてパッケージに記録された製品名
Manufacturer パッケージに記録された製品の製造元名
ProductVersion パッケージに記録された製品バージョン
ProductCode 製品を識別する製品コード
  1. 確認後は、変更を保存せずに Orca を終了します。

Property テーブルには、インストールで定義されたプロパティ名と値が格納されています。ProductName、Manufacturer、ProductVersion は、製品を特定して問い合わせ先を確認する際の手掛かりになります。

ただし、Manufacturer は MSI パッケージの作成者が設定した製造元名であり、デジタル署名によって検証された発行元名と同義ではありません。パッケージの真正性や署名者を確認する必要がある場合は、ファイルのプロパティに デジタル署名 タブが存在するかを確認し、署名の詳細と証明書の状態も併せて確認してください。署名されていないパッケージでは、デジタル署名タブが表示されない場合があります。

また、MSP ファイルは MSI ファイルと構造が異なり、同じ Property テーブルの手順では製造元を確認できない場合があります。MSP ファイルを含む削除可否の判断は行わず、まず関連する MSI の製品情報を確認したうえで、製品の開発元へお問い合わせください。

参考情報:

  • プロパティ テーブル - Win32 apps
  • Manufacturer プロパティ - Win32 apps
  • ProductName プロパティ - Win32 apps
  • ProductVersion プロパティ - Win32 apps
  • デジタル署名と Windows インストーラー - Win32 apps

まとめ

  • Windows Installer キャッシュは、一時ファイルの保管場所ではなく、製品の更新、修復、アンインストールなどに必要な領域です。
  • C:\Windows\Installer 配下を手動で削除すると、後から製品の保守処理が失敗する可能性があります。
  • すべての製品に共通する安全なキャッシュ削除手順はありません。容量削減方法は製品ごとに異なるため、製品の開発元が案内する手順に従ってください。
  • MSI ファイルに記録された製品名や製造元は、Orca の Property テーブルで確認できます。ただし、Manufacturer は署名によって検証された発行元情報ではありません。

Windows Server 2025 で NUMA スパンニングを無効にした場合の Hyper-V 仮想マシン起動動作について

Published Date: 2026-09-14
Hyper-V►Configuration and Management
feedback 共有

本記事はマイクロソフト社員によって公開されております。

こんにちは。Windows サポート チームです。

Windows Server 2025 の Hyper-V では、NUMA スパンニングを無効にした場合の仮想プロセッサの割り当て制限が厳格化されています。本記事では、NUMA スパンニングを無効にした場合の動作例を基に、Windows Server 2022 以前と Windows Server 2025 の仮想マシン起動動作の違いを説明します。

NUMA スパンニング無効時の挙動の差分概要:

Windows Server 2022 以前では、NUMA スパンニングを無効にしても、起動中の仮想マシンに割り当てられている論理プロセッサの合計が物理 NUMA ノード単位でオーバーコミットした状態でも、仮想マシンを起動できました。Windows Server 2025 では、NUMA スパンニングを無効にした場合、起動中の仮想マシンに割り当てられている論理プロセッサの合計が物理 NUMA ノード単位でオーバーコミット状態になると、仮想マシンを起動できません。

動作例の構成

本記事では、次の構成を動作例として説明します。

  • Hyper-V ホスト: 物理 NUMA ノード 2 個
  • 物理 NUMA ノードあたりの論理コア数: 16
  • NUMA スパンニング: 無効
  • 対象 OS: Windows Server 2022 以前、Windows Server 2025

単一の仮想マシンを起動する場合

仮想マシンに 24 vCPU を割り当て、仮想 NUMA ノード数を 1 に設定します。この構成では、1 つの仮想 NUMA ノードが 24 vCPU を必要とします。一方、物理 NUMA ノードあたりの論理コア数は 16 です。

NUMA スパンニングを無効にした場合、仮想 NUMA ノードは 1 つの物理 NUMA ノード内に配置される必要があります。そのため、24 vCPU を必要とする仮想 NUMA ノードを、論理コア数が 16 の物理 NUMA ノードへ配置することはできず、仮想マシンの起動に失敗します。

同じ 24 vCPU の仮想マシンで、仮想 NUMA ノード数を 2 に変更し、仮想 NUMA ノードあたりの最大プロセッサ数を 16 に設定します。この構成では、各仮想 NUMA ノードに必要な vCPU 数が物理 NUMA ノードあたりの論理コア数に収まるため、仮想マシンは起動します。

この単体仮想マシンの動作は、Windows Server 2022 以前と Windows Server 2025 で同じです。

仮想マシン構成 Windows Server 2022 以前 Windows Server 2025
24 vCPU、仮想 NUMA ノード数 1 起動失敗 起動失敗
24 vCPU、仮想 NUMA ノード数 2、ノードあたり最大プロセッサ数 16 起動成功 起動成功

複数の仮想マシンを起動する場合

24 vCPU を割り当て、仮想 NUMA ノード数を 2 に設定する仮想マシンを 3 台用意します。各仮想 NUMA ノードには 12 vCPU が割り当てられるため、各仮想 NUMA ノードに必要な vCPU 数は物理 NUMA ノードあたりの論理コア数に収まります。

Windows Server 2022 以前では、3 台すべての仮想マシンを起動できます。仮想マシン全体では 72 vCPU が割り当てられるため、物理 NUMA ノード単位では仮想プロセッサのオーバーコミットが発生します。

Windows Server 2025 では、1 台目の 24 vCPU の仮想マシンは起動します。1 台目の起動後は、各物理 NUMA ノードに 4 論理コアが残ります。2 台目の仮想マシンは、各仮想 NUMA ノードに 12 vCPU を必要とするため、物理 NUMA ノードごとに必要な vCPU を割り当てられず、起動に失敗します。

動作 Windows Server 2022 以前 Windows Server 2025
24 vCPU の仮想マシンを 3 台起動する 3 台とも起動成功 1 台目は起動成功、2 台目以降は起動失敗
物理 NUMA ノード単位の vCPU オーバーコミット 可能 不可

この違いにより、Windows Server 2022 以前では起動できていた仮想マシンが、Windows Server 2025 では起動できない場合があります。

まとめ

NUMA スパンニングを無効にした Windows Server 2025 の Hyper-V ホストでは、物理 NUMA ノード単位の仮想プロセッサ オーバーコミットはできません。Windows Server 2022 以前では起動できていた仮想マシンが、Windows Server 2025 では起動できない場合があります。

物理 NUMA ノード単位の vCPU オーバーコミットが発生する構成では、NUMA スパンニングを有効にすることをご検討ください。NUMA スパンニングの構成手順は、Hyper-V で NUMA を構成する をご確認ください。

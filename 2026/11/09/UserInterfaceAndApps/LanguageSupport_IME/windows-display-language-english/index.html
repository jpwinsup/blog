Windows の表示言語を変更しても一部の画面やアプリが英語のまま表示される場合の確認ポイント

Published Date: 2026-11-09
User Interface and Apps►Language Support
feedback 共有

本記事はマイクロソフト社員によって公開されております。

こんにちは。Windows サポート チームの吉田です。

Windows の表示言語を日本語に変更した後も、一部の画面やアプリが英語のまま表示されたり、日本語と英語が混在したりすることがあります。

この記事では、Windows の表示言語や言語パックの状態など、確認いただきたいポイントをご紹介します。

この記事で扱う事象

Windows の画面や複数のアプリで、次のような状態が発生することがあります。

  • 設定アプリなど、一部の Windows 画面が英語のまま表示される
  • 一部の画面やアプリは英語だが、ほかの画面は日本語で表示される
  • Windows の画面やアプリで、日本語と英語が混在して表示される

まず、次の 3 点をご確認ください。

  1. Windows の表示言語が日本語に設定されているか
  2. 日本語の言語パックがインストールされているか
  3. 言語パックのインストール後に、品質更新プログラムが適用されているか

症状別の確認先

表示の状態 確認先
Windows の複数の画面やアプリが英語、または表示言語が混在している この記事の「確認ポイント」をご覧ください。
Windows 11 または Windows Server 2025 のクリーン インストール後、設定アプリやエクスプローラーは日本語だが、Windows セキュリティだけが英語 Windows 11 または Windows Server 2025 のクリーン インストール後に Windows セキュリティが英語表示になる場合の対処をご覧ください。

Windows セキュリティだけが英語で表示される場合は、言語パックを入れ直す前に、リンク先の記事に沿って Windows セキュリティ プラットフォーム更新プログラム KB5007651 の適用状況をご確認ください。

確認ポイント

1. Windows の表示言語とサインアウト

[設定] > [時刻と言語] > [言語と地域] を開き、[Windows の表示言語] が [日本語] になっていることをご確認ください。

英語で表示されている場合は、[Settings] > [Time & language] > [Language & region] > [Windows display language] に相当します。

言語を追加しただけでは、Windows の表示言語は切り替わりません。表示言語を変更した後は、サインアウトしてもう一度サインインしてください。

2. 言語パックのインストール状態

[優先する言語] の一覧で [日本語] の […] を選び、[言語のオプション] を開きます。[言語パック] がインストール済みであることをご確認ください。

ダウンロードまたはインストールが完了していない場合は、完了後にサインアウトしてもう一度サインインしてください。

PowerShell では、次のコマンドでインストール済み言語やユーザーの言語設定などを確認できます。

各コマンドで確認できる内容は異なります。たとえば、MUILanguages は OS で利用できる UI 言語の一覧であり、現在のユーザーの表示言語を示すものではありません。

現在の表示言語は、[Windows の表示言語] の設定画面でご確認ください。また、Get-WinSystemLocale が示すシステム ロケールも、Windows の表示言語とは異なる設定です。

3. 言語パックのインストール後の品質更新プログラム

言語パックには、OS のリリース時点の MUI ファイルが含まれています。品質更新プログラムを適用した後に言語パックを追加すると、更新済みの OS モジュールと、言語パックに含まれる MUI ファイルとの間に差異が生じる場合があります。

その結果、一部の表示が切り替わらない、複数の言語が混在するなどの問題が発生することがあります。

言語パックを品質更新プログラムの適用後に追加した場合は、対象の Windows に適用できる最新の累積更新プログラム (LCU) の適用状況をご確認ください。言語パックの追加後に LCU を適用していない場合、LCU の再適用が問題の解消につながることがあります。

すでに LCU が適用されている環境では、Windows Update から同じ LCU がもう一度提供されない場合があります。手動で適用する場合は、Windows のバージョンに適用できる更新プログラムと手順をご確認ください。

詳しくは、次の記事をご覧ください。

  • 言語パックインストール時のご留意点

4. サインイン画面のみ英語の場合

サインイン画面など、ユーザーのデスクトップ以外の画面だけが英語の場合は、管理用の言語設定を確認します。

コントロール パネルで [地域] を開き、[管理] タブの [設定のコピー] を選びます。現在の言語設定を [ようこそ画面とシステム アカウント] に反映してください。

この操作には再起動が必要です。組織で管理されている PC の場合は、設定を変更する前に管理者へご相談ください。

この設定は、サインイン画面やシステム アカウントの表示言語を揃えるためのものです。ユーザーの設定アプリの表示言語を直接変更する設定ではありません。

5. Windows のエディション

言語を追加するときに、次のようなメッセージが表示される場合があります。

  • 「使用できる言語パックは 1 つだけです。」
  • 「Windows ライセンスでは、1 つの表示言語のみがサポートされます。」

Windows のエディションによっては、複数の表示言語を使用できない場合があります。エディションを確認し、次の公開情報をご覧ください。

  • Windows で言語とキーボード/入力レイアウト設定を管理する

6. 組織で管理されている PC の場合

組織で管理されている PC では、更新プログラムの配信元やポリシーの設定により、言語パックをダウンロードできない場合があります。

言語パックのインストールに失敗する場合は、Windows Update の状態をご確認ください。また、更新プログラムや言語に関するポリシーが設定されているか、組織の管理者にご相談ください。

切り分けの目安

確認結果 次の対応
表示言語が日本語ではない 日本語に変更し、サインアウトしてもう一度サインインします。
言語パックがインストールされていない 言語パックをインストールします。品質更新プログラムの適用状況も確認してください。
言語パックはインストール済みだが、表示が混在する 言語パックを追加した時期と品質更新プログラムの適用状況を確認します。必要に応じて対象の LCU を適用します。
サインイン画面のみ英語 [管理用の言語設定] の [設定のコピー] を確認します。
言語の追加時に「1 つだけ」と表示される Windows のエディションとライセンスを確認します。
Windows セキュリティだけが英語 Windows セキュリティが英語表示になる場合の対処をご覧ください。
上記を確認しても改善しない 次の情報をご用意のうえ、お問い合わせください。

お問い合わせいただく際にご提供いただきたい情報

上記を確認しても改善しない場合は、次の情報をご提供いただけますと、調査をスムーズに進められます。

  1. OS 情報: エディション、バージョン、OS ビルド。winver の結果もご用意ください。
  2. 事象の詳細: 英語表示になっている範囲と、該当画面のスクリーンショット。
  3. 発生時期と直前の操作: 機能更新プログラムや品質更新プログラムの適用、言語の追加・変更、イメージの展開など。
  4. 言語パックのインストール方法: 設定アプリ、DISM、オフライン適用など。
  5. 更新プログラムの適用状況: 言語パックのインストール前後に適用した LCU。
  6. 言語設定の確認結果: 次のコマンドの出力。
  1. 環境情報: 物理 PC または仮想マシンのどちらか。Azure VM などでリモート デスクトップ接続のみを使用している場合は、その旨もお知らせください。
  2. 管理方法: Windows Update の配信元 (Windows Update、WSUS など) と、言語や更新に関するポリシーの有無。
  3. 別の PC での再現有無: 同じ手順を別の PC で実施した場合の結果。

スクリーンショットを共有する際は、ユーザー名やメール アドレスなど、調査に不要な個人情報が写っていないことをご確認ください。

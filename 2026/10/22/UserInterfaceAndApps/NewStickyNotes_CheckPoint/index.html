新しい Sticky Notes を利用する際の確認ポイント

Published Date: 2026-10-22
User Interface and Apps
feedback 共有

本記事はマイクロソフト社員によって公開されております。

こんにちは、Windows サポート チームの吉田です。

Windows では、従来のデスクトップ版 Sticky Notes に加えて、OneNote for Windows で新しい Sticky Notes エクスペリエンスが提供されています。

画面や起動方法の変更に伴い、「従来の Sticky Notes で作成した付箋が表示されない」「以前と操作方法が異なる」といったお問い合わせをいただくことがあります。

本記事では、従来の Sticky Notes との主な違い、付箋を別のアプリやデバイスで確認するための同期要件、および新しい Sticky Notes を利用する際の注意事項をご紹介します。

概要

Windows 上の OneNote フィードは、新しい Sticky Notes エクスペリエンスに置き換えられています。なお、OneNote for the web や Outlook on the web など、その他の OneNote フィードの提供先に変更はありません。

詳細については、Microsoft OneNote で OneNote フィードを使用する をご確認ください。

従来の Sticky Notes では、Sticky Notes バージョン 3.0 以降で Microsoft アカウントを使用してサインインすることで、アプリやデバイス間で付箋を同期できます。また、OneNote フィードは、OneNote で使用している同じ Microsoft アカウント、または職場または学校アカウントに関連付けられたノート (メモ) を同期します。

既存の付箋が表示されない場合は、最初に次の点をご確認ください。

  • 従来の Sticky Notes で付箋が同期されているか
  • 従来の Sticky Notes と OneNote で、対象の付箋に関連付けられたアカウントを使用しているか
  • Sticky Notes と OneNote が最新の状態になっているか
  • 同期エラーが表示されていないか

付箋を別のデバイスや Web で表示する方法については、他のデバイスと Web で付箋を表示する をご確認ください。

1. 従来の Sticky Notes アプリと新しいエクスペリエンス

従来の Sticky Notes は、Windows のスタート メニューなどから起動するデスクトップ アプリです。一方、Windows 上の OneNote フィードは、新しい Sticky Notes エクスペリエンスに置き換えられています。

項目 従来の Sticky Notes 新しい Sticky Notes エクスペリエンス
主な表示場所 Windows の Sticky Notes アプリ Windows 上の OneNote
同期 Sticky Notes バージョン 3.0 以降で、対応するアカウントにサインインして同期 OneNote で使用しているアカウントに関連付けられた同期済みの付箋を表示
その他の表示先 Web、Outlook、対応するモバイル版 OneNote など OneNote for the web や Outlook on the web などの OneNote フィードも引き続き利用可能

機能は段階的に展開される場合があります。最新の情報は、次のページをご確認ください。

  • Microsoft OneNote で OneNote フィードを使用する
  • 付箋を開始する

2. 利用前に確認すること

2.1 従来の Sticky Notes のバージョンを確認する

Sticky Notes のバージョンが 3.7.106 以下の場合、ノート (メモ) をクラウドと同期するには最新バージョンへの更新が必要です。

確認手順は次のとおりです。

  1. 従来の Sticky Notes を開きます。
  2. ノート (メモ) の一覧から 設定 を開きます。
  3. バージョン情報 セクションまでスクロールします。
  4. 表示されるバージョン番号を確認します。
  5. 3.7.106 以下の場合は、Microsoft Store または組織で定められたアプリの配布方法を使用して更新します。

詳細については、Sticky Notes のトラブルシューティング の「アプリを更新するための通知が表示され続ける」をご確認ください。

企業や学校など、Microsoft Store の利用が制限されている環境では、アプリの更新方法について組織の IT 管理者へご確認ください。

2.2 サインインしているアカウントを確認する

Sticky Notes バージョン 3.0 以降では、同じ Microsoft アカウントを使用してサインインすることで、アプリやデバイス間で付箋を同期できます。また、OneNote フィードでは、OneNote で使用している Microsoft アカウント、または職場または学校アカウントに関連付けられたメモが同期されます。

複数のアカウントを使用している場合は、現在表示しているアカウントが、対象の付箋を同期したアカウントであるかをご確認ください。

詳しくは、Sticky Notes はどこに行きましたか? をご確認ください。

2.3 従来の Sticky Notes で同期を実行する

  1. Sticky Notes を開きます。
  2. ノート (メモ) の一覧を表示します。
  3. 右上の 設定 を開きます。
  4. 今すぐ同期 を選択します。
  5. 同期エラーが表示されないことを確認します。

操作の詳細については、Sticky Notes のトラブルシューティング の「付箋が他のデバイスに表示されない」をご確認ください。

3. Exchange Online メールボックスに関する注意事項

現在、OneNote の Sticky Notes で付箋を保存および同期するには、Exchange Online メールボックスが必要です。

特定の構成では、次の内容を含む同期エラーが表示されることがあります。

現在、Sticky Notes には同期用の Exchange Online メールボックスとストレージが必要です。

このエラーが発生した後に新しく作成または編集した付箋は同期されず、データはアプリ内にローカルでのみ保存されます。この状態では、付箋はバックアップされません。また、オンプレミスの Microsoft Exchange メールボックスは、この同期機能のサポート対象ではありません。

エラーが表示される場合は、組織の IT 管理者へ Exchange Online メールボックスの利用状況をご確認ください。

詳細については、Microsoft OneNote の付箋における同期エラーのトラブルシューティングを行う をご確認ください。

[!CAUTION]
上記の同期エラーが発生した後に作成または編集した付箋は、ローカルにのみ保存されている場合があります。アプリのリセット、アンインストール、端末交換などを行う前に、必要な内容を別の場所へコピーするなど、データを保全してください。

4. 新しい Sticky Notes に付箋が表示されない場合

手順 1: 使用しているアカウントを確認する

従来の Sticky Notes と OneNote で、対象の付箋に関連付けられたアカウントを使用しているか確認します。

OneNote フィードで別のアカウントへ切り替える手順については、Microsoft OneNote で OneNote フィードを使用する をご確認ください。

手順 2: 従来の Sticky Notes の同期状態を確認する

従来の Sticky Notes で 今すぐ同期 を実行し、エラーが表示されないことを確認します。

手順 3: アプリを更新する

Sticky Notes と OneNote を、Microsoft Store または組織で承認された方法により最新の状態へ更新します。

手順 4: 別の表示先でも確認する

同期済みの付箋は、Web、Outlook、対応するモバイル版 OneNote などから確認できます。サポートされる表示先と確認方法については、他のデバイスと Web で付箋を表示する をご確認ください。

5. 利用時の注意事項

アプリを削除またはリセットする前に付箋を確認する

Sticky Notes にサインインしていない状態でアプリをアンインストールまたはリセットすると、ローカルの付箋が削除されます。

新しい Sticky Notes や別の表示先で必要な付箋を確認できるまでは、従来の Sticky Notes のアンインストール、リセット、アプリ データの削除を行わないでください。

詳細については、Sticky Notes はどこに行きましたか? の「予期せずアンインストールされた Sticky Notes」をご確認ください。

付箋の削除は元に戻せない

削除した付箋は元に戻すことができません。誤削除を防ぐため、Sticky Notes の設定で 削除する前に確認 を有効にしてください。

詳細については、Sticky Notes はどこに行きましたか? の「メモを削除しました。再び入手するにはどうすればよいですか」をご確認ください。

アカウントを切り替えると表示される付箋が変わる

付箋がアカウントに同期されている場合、別のアカウントへ切り替えると、以前のアカウントに関連付けられた付箋が表示されなくなる場合があります。付箋が見つからない場合は、以前使用していたアカウントでサインインしているか確認してください。

6. 管理された企業環境での補足

Microsoft Store へのアクセスやアプリの更新が組織によって管理されている場合は、アプリの再インストールやリセットを行う前に、組織の IT 管理者へご相談ください。

確認時には、次の情報を記録しておくと調査に役立ちます。

  • Sticky Notes のバージョン
  • OneNote のバージョン
  • サインインしているアカウントの種類
  • 表示されたエラー メッセージとエラー コード
  • エラーの発生日時
  • 従来の Sticky Notes で 今すぐ同期 を実行した結果
  • Web や別のデバイスで付箋を確認できるか

まとめ

  • Windows 上の OneNote フィードは、新しい Sticky Notes エクスペリエンスに置き換えられています。
  • 既存の付箋が表示されない場合は、アカウント、同期状態、アプリのバージョンを確認します。
  • Sticky Notes のバージョンが 3.7.106 以下の場合は、同期を継続するために最新バージョンへ更新します。
  • 現在、OneNote の Sticky Notes で付箋を保存および同期するには、Exchange Online メールボックスが必要です。
  • 同期済みであることを確認する前に、従来の Sticky Notes のアンインストール、リセット、アプリ データの削除を行わないでください。
